# 文风定量画像

> 本文讲通用测量方法，不包含任何真实作者文本、个人目标带、样本数量或内部统计。

## 画像对象与样本筛选

文风画像描述的是**某类作者在某种场景下的写法**，不是好坏评分。先按文体、场景、受众和口语/书面语分组，再建立可比较样本；长文、群通知和群聊不共用一个目标带。

建立画像前，先确认样本由作者授权使用，且与当前任务足够相似。排除转载、引文占比过高、多人混写、模板占主导或被大幅代改的文本；来源和处理方式要记录在本地。公开方法只描述筛选办法，不提交样本文本、原始统计、样本数量或个人画像值。汇总后的画像也可能具有识别性，不能因为去掉姓名就自动视为可公开。

## 指标与目标带

根据任务选择指标，不要求每篇文字都计算全部指标。可选六类：

1. **词汇**：词汇丰富度（如 STTR/MTLD）、实词密度、词长、高频实词和常见搭配。
2. **句法**：平均句长、句长离散、长短句比例、逗号/句、小句/句；能稳定计算时再考虑依存距离等复杂指标。
3. **功能词与话语标记**：代词、连词、语气词和“然后/但是/其实”等标记的频率，必要时看句首占比。
4. **标点与形式**：标点频率、组合、段落长度、每段句数和空行频率。
5. **重复**：字符或词语 n-gram 重复、口头禅和模板句密度。
6. **口语特征**：语气词、填充词、自我修正、停顿标点，以及口语词与书面词的比例；只在口语任务启用。

每个指标都要固定统计口径。中文按“字”“词”或“句”计数时不可混用；句子切分、分词和标点归一化方式要保持一致。无法稳定计算的指标标为“近似”或“不适用”，不拿不同工具、不同口径的结果直接比较。

### 目标带怎么定

对同一作者、同一场景下足够多且质量可比的样本，按指标分布设置描述性区间；可用 P25–P75 表示中间一半样本所在范围。不要把多个场景合并后用一个区间，也不要把目标带当硬性评分。

样本太少、文本太短或指标不稳定时，不要制造精确感。可将均值附近的范围（例如均值 ±0.5 个标准差）作为临时、可复算的操作性参考，只表达当前小样本中心附近的波动；它不是置信区间，也没有普遍的理论最优性。应标注“样本少/不稳定”，不据此推断作者固定特征；若这种启发式不适合任务，就只报告观察结果，不设目标带。正式使用前，应说明样本下限和区间算法。

权重不是必需项。确需综合分数时，要先说明为什么某些维度更重要，并让权重可配置；公开版本不沿用任何个人画像里的权重或目标值。

## 自动检查与人工解释

检查报告至少显示：指标定义、样本量、目标区间、当前文本值、稳定性提示、偏离方向和可选动作。脚本负责计数和比较，不决定“像不像”或“好不好”。

先选与当前文体有关的指标，再看偏离是否有实际影响。若调整会损害事实、语气、清晰度或用户表达意图，就保留原文并说明原因。指标仅是描述工具，内容质量与读者需求优先。

## 纯示意数据

以下数值是人工构造的纯示意数据，**不是任何真实作者或写作任务的观察结果、目标带或样本统计**。为演示计算，临时构造一组虚构的句长值：

