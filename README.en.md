# AI-Assisted Writing Workflow

[中文](README.md) | [English](README.en.md)

This repository documents AI-assisted methods developed and refined through writing tasks. It focuses on task routing, coordinating Skills, writing-style analysis, staged revision, and review before delivery. The workflow can be adapted to the author's texts, available tools, and task constraints.
