# 一种类似于 Boosting 或者 Pipeline 思想的 AI Agent 辅助写作工作流

本项目整理一套实际使用过的 AI 辅助写作方法。

目前主要的想法是多个 Skill 在工作逻辑上的组合，以及可以用自己的文本、工具和约束来得到符合本人文风的文字。

## 数据与引用边界

项目中只使用了重新编写的虚构示例和通用方法。

有关定量的章节用了虚构的示意数值。

实际使用了多个第三方的写作相关的 Skills，记录了名称、来源链接和核验日期；能确认的上游提交、版本和许可一并记录，无法确认的标为未知。没有复制他们的提示词。
