# AI 辅助写作工作流：Skills 编排、文风量化与质量验收

本项目整理一套实际使用过、可迁移到其他写作任务的 AI 辅助写作方法。读者可以用自己的文本、工具和约束来复现，不需要也不应获取本人的训练语料。

## 适用对象

先供少量协作者使用；方法成熟后，可考虑公开。核心内容讲流程、工具分工、定量分析和验收，不收录个人原稿、微信语料、真实修改片段或个人文风目标带。

## 数据与引用边界

只使用重新编写的虚构示例和通用方法。定量章节如需演示，只用明确标注为虚构的示意数值，不把它们写成实测结果。引用第三方 Skills 时记录名称、来源链接和核验日期；能确认的上游提交、版本和许可一并记录，无法确认的标为未知，不凭同名猜作者。只说明本项目如何编排，不复制其提示词或正文。
